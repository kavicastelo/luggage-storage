# 01 — Product-Wide UX Audit & Experience Architecture (`WS-UX-01`)

**Scope:** Complete inventory and user-experience audit across Traveller Web, Auth/Account/System Web, Host Workspace Web, Superadmin & Support Web, and Expo Mobile (`apps/web` & `apps/mobile`).

---

## 1. Executive Audit Summary

While Initiatives 1–7 established solid domain logic, RBAC, custody cryptography, ledger accounting, and CWCP palette tokens (`packages/contracts/src/tokens.ts`), five systemic UX fractures make the current product feel uneven and administrative:

1. **Fragmented Brand & Visual Language:** Web Auth, Account, Error pages, and `ScreenHeaderBadge` still use legacy `slate-*` / `blue-600` styling; `index.html` fails to load `Plus Jakarta Sans` and `JetBrains Mono`; Mobile mixes `"BagBox Sri Lanka"` and `"Luggage Storage Marketplace"` instead of a unified `"LuggageStorage"` identity.
2. **Broken Mobile & Responsive Navigation:** Web `AppShell` hides `<nav>` on `< lg` screens with **no hamburger menu or drawer**. Admin & Host sidebars stack vertically above content on tablets/phones. Mobile `DiscoveryView` overlaps the top status bar (`insets.top` missing), `(host)/_layout.tsx` overlaps the bottom home indicator (`insets.bottom` missing), and `app/booking/confirm.tsx` puts `SafeHeader` inside the scroll body.
3. **Inline "Fake Drawers" & Unaccessible Modals:** 7 Admin pages render inspection/action panels **below the full 20-row table** with zero focus or scroll feedback. Host & Traveller Portal modals lack `role="dialog"`, `aria-modal="true"`, Escape close, and height containment. Mobile `BottomSheet` cannot be dismissed by tapping its backdrop and lacks `KeyboardAvoidingView`.
4. **Flash-of-Empty-State & Missing Visual Evidence:** 6+ Admin/Host screens render empty-state cards or `0` KPIs while queries are still loading. Facility photos (`AdminLocationModerationPage`) and custody evidence photos (`AdminBookingsLedgerPage`, `AdminIncidentsDisputesPage`) render raw URL text links instead of inline image thumbnails.
5. **Underutilized & Boxed Mascot Assets:** All 20 transparent-background Kiri illustrations exist in WebP/PNG, yet Web only uses 2 in real Traveller/Error screens while placing boxed mascots inside **10 dense Admin data-table headers**. Mobile wraps transparent Kiri illustrations in heavy bordered boxes even inside dark navy hero cards and `Card`-wrapped `EmptyState`s.
